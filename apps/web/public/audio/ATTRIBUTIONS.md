# Adding Audio attributions

This file records the source and license for every audio asset shipped with
BitWars. It is deployed with the game at `/audio/ATTRIBUTIONS.md`.

## Background music

Add one entry for each track and retain the title, creator, source, license,
and any changes made to the original work.

### Track title

- Files: `music/track-title.ogg`, `music/track-title.mp3`
- Artist: Creator name
- Source: https://example.com/original-work
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Changes: Trimmed for looping; encoded as OGG and MP3.
- Retrieved: YYYY-MM-DD

## Sound effects

Add future sound effect credits here using the same fields.
